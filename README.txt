===================================================
 Netlify + Decap CMS ওয়েবসাইট সেটআপ করার নির্দেশিকা
===================================================

এই জিপ (ZIP) ফাইলের ভিতর আপনার ওয়েবসাইটের সব রেডি কোড দেওয়া আছে।

ধাপ ১: GitHub-এ আপলোড করা
-----------------------------------------
১. https://github.com-এ যান এবং অ্যাকাউন্ট খুলুন।
২. "New repository" তৈরি করুন (যেমন: my-blog-site)।
৩. এই ZIP ফাইলটি আপনার কম্পিউটারে/ফোনে আনজিপ (Unzip) করে সবগুলো ফাইল গিটহাবে আপলোড (Upload files) করে দিন।

ধাপ ২: Netlify-তে ওয়েবসাইট ফ্রিতে চালু করা
-----------------------------------------
১. https://www.netlify.com-এ যান এবং "Sign up with GitHub" দিয়ে লগইন করুন।
২. "Add new site" -> "Import an existing project" নির্বাচন করুন।
৩. গিটহাব থেকে আপনার আপলোড করা প্রজেক্টটি (my-blog-site) সিলেক্ট করে "Deploy" চাপুন।

ধাপ ৩: ইউজারদের পোস্ট করার অপশন চালু করা
-----------------------------------------
১. Netlify ড্যাশবোর্ডে "Site Configuration" -> "Identity"-তে যান।
২. "Enable Identity service" বাটনে ক্লিক করুন।
৩. নিচে "Registration preferences" থেকে "Open" নির্বাচন করুন।
৪. "Services" -> "Git Gateway"-তে গিয়ে "Enable Git Gateway" চালু করে দিন।

এখন যেকোনো ভিজিটর আপনার ওয়েবসাইটের শেষে /admin/ লিখলেই (যেমন: your-site.netlify.app/admin/) লগইন/সাইনআপ করে কোনো ডাটাবেজ ছাড়াই সরাসরি পোস্ট করতে পারবে!
